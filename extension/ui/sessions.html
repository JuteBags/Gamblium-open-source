What putting tabs away keeps, and what it cannot

Kept

Each window with its place and size. Every tab in order with its address, pin, group, mute and zoom. Scroll position and the text typed into forms, if you leave that on. Gamblium's settings as they were.

Not kept

What lives only in a page's memory: an unsaved document in an editor, a game in progress. A tab's Back and Forward history. Passwords and card numbers.

Files

An exported set of tabs opens in another profile or on another computer. The file holds page addresses and any form text that was kept, so treat it as private.
